# WeatherStationPages

This repository is automatically populated by the GitHub Actions CI pipeline in the main [WeatherStation](https://github.com/emmby/WeatherStation) repository.

It uses GitHub Pages to serve static assets (such as weather icons, manifests, and potentially OTA binaries in the future) for the ESP32 Inkplate Weather Station firmware.

- **Main Repository:** [https://github.com/emmby/WeatherStation](https://github.com/emmby/WeatherStation)
- **Asset Base URL:** `https://emmby.github.io/WeatherStationPages/`

> [!NOTE]
> Do not manually edit the contents of this repository, as they may be overwritten by automated deployments.
